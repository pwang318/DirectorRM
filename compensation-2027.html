Access and data protection

This is currently a public GitHub Pages application using shared browser-side data access. It is not a private payroll portal. Avoid entering confidential borrower details, private compensation notes, or other sensitive records. Before using this with a broader audience, implement authenticated Director-only access and database row-level permissions in a coordinated rollout so RM and LP data workflows are not disrupted.
